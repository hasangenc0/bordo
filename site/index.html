One sentence in. A running service out.

Bordo scaffolds the project, builds the image in GitHub Actions, and deploys it to a server you own. You get a URL back. Self-hosted, driven by an agent or a few CLI commands.

you   › create a java web service called hello-api and ship it
bordo › ✓ scaffolded hello-api from java-web-service
        ✓ image built in GitHub Actions, pushed to GHCR
        ✓ deployed to k3s on your server
        ✓ live at http://your-server:3xxxx/
Install in 5 minutes ★ Star on GitHub

You need: a Linux server with Docker, a GitHub account, and a DeepSeek API key.

What you skip writing

Without Bordo

  • A Dockerfile
  • A CI workflow to build and push it
  • Kubernetes manifests
  • A registry login on the cluster
  • Cluster credentials for your deploy tool

With Bordo

  • One sentence to the agent
  • Or bordo project create, then bordo deploy create
  • A URL back

What you get

Runs on a $5 VPS

One Linux box with Docker is enough. Bordo installs k3s for you.

Builds stay off your server

Images build in GitHub Actions and publish to GHCR, so the server only runs them.

Multi-region

bordo region add prints one command. Run it on another machine and it joins the fleet.

No keys left lying around

Servers join with a one-time token. The control plane stores no SSH keys and no cluster-admin credentials. Each cluster pulls its own config.

Observability included

OpenTelemetry, VictoriaMetrics, Loki and Tempo. Ask the agent for logs or a rollback.

Console and CLI

Chat, apps, regions, metrics and logs in the web console, or the same from bordo in a terminal.

How it works

Bordo never builds on your server. Your code and images live in your own GitHub account.

Install

Before you start, have:

  • A Linux server with Docker and at least 25 GB of disk. A $5 VPS works. Bordo shows how full each disk is and warns before it fills.
  • A GitHub account. Bordo asks you to authorize it during setup.
  • A DeepSeek API key.
  • Ports 3000 (console) and 7401/7402 (API) reachable from you. Use a firewall rule or an SSH tunnel.

  1. Install the CLI on your server

    curl -fsSL https://raw.githubusercontent.com/hasangenc0/bordo/master/install-cli.sh | sh

  2. Run setup

    Installs and starts Bordo, reads the setup token for you, asks for your DeepSeek API key, then shows a short code to enter at GitHub.

    bordo setup

  3. Ship something

    bordo agent chat
› create a java web service called hello-api and build it
› deploy hello-api and expose it to the internet
Got a live URL? A star on GitHub is how other people find this. Something broke? Open an issue, setup problems are the ones I want to fix first.
Prefer a browser for setup?

Run bordo platform install and bordo platform up, then open the console at http://your-server:3000. It asks for the DeepSeek key, then walks you through connecting GitHub. Login: bordo platform password.

Script it, or skip the prompts

Run setup straight after installing with BORDO_SETUP=1, or pass the key and skip GitHub:

DEEPSEEK_API_KEY=sk-... bordo setup --skip-github
Plain commands instead of the agent 
bordo project create hello-api --template java-web-service
bordo build trigger hello-api
bordo deploy create <project-id> <image> --region <region> --expose nodeport
What does setup change on my machine?

The installer puts one bordo binary in /usr/local/bin (or ~/.local/bin). Setup writes a compose file to ~/.bordo/deploy and starts the Bordo containers. Stop them with bordo platform down. To remove everything, run that, then delete ~/.bordo and the binary. You can read the install script first.

HTTPS on your own domain

Deploy with --expose ingress --host app.yourdomain.com and point your domain at the server.

FAQ

Where does my DeepSeek key go?

Into the settings store of the control plane running on your server. It is sent to DeepSeek when the agent calls the model, and nowhere else.

Can I use a different model?

Setup lets you change the model and the LLM base URL with bordo setup --advanced. Anything that speaks the same API works.

How is this different from Coolify or Dokploy?

Those deploy code you already wrote. Bordo also scaffolds the project from a template, writes the Dockerfile and CI workflow, and lets an agent run the whole loop from one sentence.

Does it cost anything?

Bordo is free and Apache 2.0. You pay for your server and for DeepSeek API usage. GitHub Actions minutes are on your own account.

Is it production ready?

It is early. The deploy path works end to end and is tested live, but expect rough edges. Good for side projects and internal tools today.
